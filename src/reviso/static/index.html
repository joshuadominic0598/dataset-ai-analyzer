START HERE

What should we learn from this data?

One file is enough. These answers guide the analyst's questions and the resulting report. You can also discuss them in chat.

01

What identifies a record?

Choose fields that identify what one row represents. This helps find repetitions in one file and match records across versions. Leave blank if unsure.

Hold Ctrl / ⌘ to select a combination.
02

Which fields matter most?

Analytic Brain will prioritize changes to these fields. Tell it what positive and negative changes mean for your use case.

03

Would meaning-based search help?

Description fields can be embedded for semantic retrieval. Numeric and short category fields stay in SQLite.

Uses your selected provider after you build the index. Local Ollama embeddings stay on this machine; Groq chat can use a separate embedding connection.
04

Set the boundaries.

Your snapshots remain local. AI analysis sends selected metrics, field names, and bounded record samples to your chosen provider. Text indexing sends every selected nonempty text cell.

Only empty or whitespace-only cells count as missing. NA, None, and 0 retain their original meaning.
05

Do renamed fields mean the same thing?

Similar values suggest a link, but you decide whether the meaning and unit stayed the same. Your decision applies to the next report.

What do the fields mean?

Nominal categories have no order; ordinal categories have an order. Numeric codes may be labels. These are suggestions until you confirm them.

Field / suggestion Meaning Ordered labels (optional)
For ordered labels, enter the order from lowest to highest separated by |, such as Low | Medium | High. Values outside your order will be flagged.
